# Windows overlay

Mini: tên build. Compact: item/lõi tham khảo. Expanded: thêm ghi chú. Ctrl+Shift+O ẩn/hiện, Ctrl+Shift+Space đổi chế độ, Ctrl+Shift+I click-through, Ctrl+Shift+C mở bảng. F8 không quét live trong advanced.

Widget order: kéo thả trong Settings hoặc nút lên/xuống; độ đậm 0.5–1, export/import layout schema1. Vị trí bị giới hạn theo cạnh trái/phải và khoảng dọc để chừa HUD; không phải freeform grid editor. DisplaySetup giữ monitor/resolution/window mode; các thông số layout nhập được sanitize.

Window DPI geometry kiểm bằng bộ test trên preset độ phân giải, scale 1/1.25/1.5/2 và tọa độ âm; monitor removed được clamp/reposition. Capture thật với Electron ở 860×620,1280×800,1920×1080 và zoom150%. Chưa xác minh DPI thật trên 2 màn hình hoặc full-screen exclusive trong trận.

Không thể nhận tự động màn chọn lõi khi live OCR khóa; auto-hide bằng Tab/focus và phím ẩn/hiện vẫn hoạt động. Main dashboard là companion window có thể kéo sang màn hình phụ. Chưa có nhiều cửa sổ workspace độc lập hay kéo resize từng widget trực tiếp trên desktop.
